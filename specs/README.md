# Specs Index

This tree is the authority surface for Premath.

Read order:

- `premath/README.md` — Premath-specific authority map.
- `premath/AUTHORITY-MAP.json` — machine-readable authority classification for
  core, profiles, control-plane surfaces, and raw holding areas.
- `premath/draft/SPEC-INDEX.md` — authority front door for active claims,
  profiles, raw/default status, and adjacent-site boundaries.
- `premath/draft/README.md` — promoted draft contract map.
- `premath/profile/README.md` — optional profile overlays, normative only when
  explicitly claimed.
- `premath/raw/README.md` — exploratory and informational work that has not
  been promoted.
- `raw/README.md` — absorbed raw identity/ASP/JWT pack; non-promoted and not
  Premath Core.
- `process/README.md` — lifecycle, governance, and promotion process.

Boundary rule:

- `specs/` owns normative contracts, lifecycle policy, and promoted machine
  contracts.
- `docs/` explains implementation shape and operator workflow. It can point
  here, but it does not create parallel authority.
- `specs/raw/` is a holding bay for absorbed or candidate material. It is not
  promoted merely by living in this repository.
